Low-Level Optimization

RISC-V Vector Execution

We bypassed generic C++ reference kernels that map onto standard Add/Mul instructions which cause tiny INT8 accumulator overflows (an 18% accuracy divergence on simulators). Instead, we inject explicit Vector instructions handling rounding cleanly.

bash 
riscv-none-elf-gcc -O3 \
    -march=rv64gcv -mabi=lp64d \
    -DTF_LITE_USE_GLOBAL_CMATH_FUNCTIONS \
    main.cc model_data_uci.cc \
    libtensorflow-microlite.a \
    -o tinyml_sim_exec
